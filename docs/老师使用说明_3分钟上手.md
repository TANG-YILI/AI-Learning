# 老师使用说明（3分钟上手，无需技术背景）

## 这个工具是做什么的

这是一个“IPO项目建议书自动生成”工具。  
您只需打开网页，加载样例或填写公司信息，点击按钮即可生成建议书，并下载 PDF。

## 适用场景

- 快速查看某企业 IPO 初步建议框架
- 形成内部讨论初稿（公司亮点、行业分析、估值参考、上市方案、重点事项）
- 作为人工判断前的辅助材料

## 如何使用（最简 4 步）

1. 打开链接（由我邮件提供）
2. 点击“加载华泰题目样例”（已预置）
3. 点击“生成项目建议书”
4. 点击“下载PDF（建议发老师）”

## 输出内容包含什么

1. 公司亮点  
2. 行业分析  
3. 估值参考（PE+PS两种方法，并给出估值区间）  
4. 上市方案设计  
5. 重点关注事项（含解决思路）  

## 说明

- 本工具用于提升初稿效率，不替代专业判断；
- 输出为研究与讨论用途，不构成投资建议或上市结果承诺。
