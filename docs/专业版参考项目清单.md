# 专业版参考项目清单（可用于说明你对行业最佳实践有研究）

以下项目可作为“终稿级报告系统”的参考方向。你可以在邮件或面试中说明：当前 Demo 已完成承做核心框架，下一步可按以下成熟范式迭代。

## 1) sellside-research-engine
- 链接：<https://github.com/DogInfantry/sellside-research-engine>
- 可借鉴点：
  - 多场景估值（DCF + Reverse DCF + Comps）
  - 机构风格研究报告结构化输出
  - 图表化（敏感性矩阵、football field）

## 2) FinSight（ACL 2026）
- 链接：<https://github.com/RUC-NLPIR/FinSight>
- 可借鉴点：
  - 多Agent流水线（采集 -> 分析 -> 生成）
  - 一键生成“可发布级”长报告
  - 报告模板化与导出能力（MD/DOCX/PDF）

## 3) FP-DCF
- 链接：<https://github.com/tiejiang8/FP-DCF>
- 可借鉴点：
  - 可审计估值引擎（FCFF -> WACC -> DCF）
  - 估值过程结构化输出，适合风控复核
  - 敏感性分析与诊断信息输出

## 4) due-diligence-agents
- 链接：<https://github.com/zoharbabin/due-diligence-agents>
- 可借鉴点：
  - 跨领域尽调并行分析（法律/财务/税务/合规等）
  - 可追溯证据链（条款定位、引用）
  - 更接近机构内部“IC材料”风格

## 建议你对外表达的话术

“我当前完成的是 IPO 承做场景的可运行 MVP，重点验证输入结构化、估值可复核、风险可披露、报告可导出。  
下一步将按机构级框架演进：引入可审计 DCF 引擎、证据链追溯与多Agent协同，以达到终稿化交付标准。”
