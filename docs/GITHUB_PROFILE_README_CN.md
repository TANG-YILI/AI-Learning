# 唐一立｜IPO承做AI Agent 项目说明

## 项目定位

本项目面向投行股权承做场景，目标是将“公司信息报表 -> IPO建议书输出”流程结构化、自动化、可复核化。  
重点不在于生成文案本身，而在于把承做业务拆解成可执行的 AI 工作流。

## 我解决了什么问题

- 传统痛点：初稿整理和重复性底稿耗时，输出风格不统一；
- 我的方案：输入结构化数据，自动产出标准化 IPO 建议书；
- 关键价值：提高效率、统一框架、保留人工复核边界。

## 功能概览

- 输入：业务描述、财务报表、可比估值、风险清单、募资用途；
- 分析：自动计算收入 CAGR、净利率、EBITDA Margin、估值中枢；
- 输出：项目概览、投资逻辑、财务诊断、估值建议、风险披露、执行时间表；
- 交付：Web 页面展示 + Markdown/PDF 导出。

## 技术实现

- `Streamlit`：可视化交互和演示；
- `LiteLLM`：对接大模型（可选）；
- `Deterministic Fallback`：无 API Key 时仍可稳定演示；
- `ReportLab`：报告 PDF 导出。

## 快速运行

```bash
uv sync
uv run streamlit run app.py
```
