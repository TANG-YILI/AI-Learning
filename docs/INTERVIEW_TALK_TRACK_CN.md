# 面试 3 分钟讲解稿（唐一立版）

## 20秒自我引入

我是唐一立，这次我做的不是简单的“AI写文案”，而是把 IPO 承做里可标准化的环节工程化成一个可运行的 Agent。  
目标是让 AI 在承做中承担“高频、可复核”的部分，提升效率但不替代关键判断。

## 50秒讲核心思路

我把输入定义为结构化公司信息：业务、财务、可比估值和风险。  
然后按承做逻辑输出一份 IPO 建议书，覆盖项目概览、投资逻辑、财务诊断、估值建议、风险披露和执行时间表。  
重点是保留测算链路，比如收入 CAGR、利润率、可比倍数中枢，确保结果可解释、可复核。

## 60秒讲落地形态

1. 输入层：网页端贴入 JSON 数据；  
2. 分析层：自动计算核心财务与估值指标；  
3. 生成层：按投行语境形成结构化建议书；  
4. 交付层：一键导出 Markdown/PDF，便于汇报和讨论。  

我还加了 deterministic fallback，所以即使没有 API Key 也能稳定演示，避免面试现场失效。

## 35秒讲业务价值

- 对团队效率：减少重复性底稿整理和初稿撰写时间；  
- 对质量控制：统一输出框架，降低关键信息遗漏；  
- 对风险控制：强调风险披露和审慎措辞，不做结果承诺。  

## 15秒结尾

如果老师愿意，我可以现场用一组样例企业数据，2 分钟演示从输入到报告导出的完整流程。
